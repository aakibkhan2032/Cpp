## ▶️ How to Compile and Run

Make sure a C++ compiler is installed on your system.

**1. Compile a program**

```bash
g++ single_inheritance.cpp -o single_inheritance
```

**2. Run the executable**

```bash
./single_inheritance
```

Run these commands from the directory containing the source file. Replace the filename with the program you want to execute.
